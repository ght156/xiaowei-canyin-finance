# 小微餐饮财务管理系统

面向乡镇小餐饮店（面食店、早餐店等）的轻量记账与经营分析系统。目标：**简单记账、自动算利润、安全备份、可扩展**。

- 店主在手机上 5～10 秒完成一笔收入/支出记录
- 自动汇总今日 / 本月 / 任意区间的收入、支出、利润和利润率
- 多店铺独立核算与合并汇总
- 软删除回收站、操作审计日志、每日自动备份
- PWA 支持，手机浏览器可"添加到主屏幕"

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Vant 4（移动端优先）+ PWA + ECharts + Pinia |
| 后端 | FastAPI + SQLAlchemy 2.x |
| 数据库 | SQLite（单文件，备份即复制文件） |
| 鉴权 | JWT + RBAC（管理员 admin / 店主 owner） |
| 测试 | pytest（44 个用例，覆盖利润计算与权限校验） |

金额在后端与数据库中一律以 **"分"为单位的整数** 存储与计算，API 层使用两位小数字符串传输，杜绝浮点误差。

## 目录结构

```
├── backend/            # FastAPI 后端
│   ├── app/            # 应用代码（models / routers / services / security）
│   ├── tests/          # pytest 自动化测试
│   ├── seed.py         # 数据库初始化脚本（分类 + 店铺 + 测试账号）
│   └── requirements.txt
└── frontend/           # Vue 3 前端
    ├── src/views/      # 登录 / 首页 / 记账 / 流水 / 分析 / 我的
    └── vite.config.js  # 含 PWA 与开发代理配置
```

## 快速开始

### 1. 后端

```bash
cd backend
python -m pip install -r requirements.txt

# 初始化数据库（幂等，可重复执行）
python seed.py

# 启动（默认 http://127.0.0.1:8000）
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 2. 前端

开发模式（带热更新，自动代理 /api 到 8000 端口）：

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

生产模式（推荐，手机直接访问后端即可）：

```bash
cd frontend
npm run build      # 生成 dist/
# 重启后端后，直接访问 http://<电脑IP>:8000
```

### 3. 测试账号

| 账号 | 密码 | 角色 | 权限 |
|---|---|---|---|
| admin | admin123 | 管理员 | 店主权限 + 修改历史数据、删除/恢复、店铺与分类管理、用户管理、导出、备份恢复、操作日志 |
| owner | owner123 | 店主 | 记账、查看流水与经营数据 |

> 首次部署后请立即在"我的 → 用户管理"中修改默认密码。

## 主要功能

- **快速记账**：记收入 / 记支出，金额默认聚焦、数字键盘、分类宫格、默认今天
- **流水管理**：按店铺 / 类型 / 分类 / 日期区间（今天、近 7 天、本月、上月、自定义）筛选，按日分组合计
- **经营分析**：按日 / 按月 / 自定义区间的收入、支出、利润、利润率（收入为 0 显示 "—"）；收入支出趋势图、支出构成饼图、分店铺明细
- **店铺管理**：多店铺（默认面食店、早餐店），可新增、停用
- **分类管理**：2 类收入 + 15 类支出预置，管理员可新增、改名、停用、排序
- **数据安全**：
  - 删除一律软删除，回收站可恢复（仅管理员）
  - 修改 / 删除 / 恢复全部写入审计日志（含修改前后值）
  - 每天首次启动自动备份数据库，保留最近 30 份，可手动备份 / 从备份恢复
  - 流水导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）

## 利润口径

第一版采用**经营现金口径**：`经营利润 = 区间收入 − 区间支出`，`利润率 = 利润 ÷ 收入 × 100%`。
房租、设备等按实际付款日期计入，不等同于正式会计报表。

## 数据备份与恢复

- 备份文件位于 `backend/data/backups/`（SQLite 在线备份，复制期间可正常记账）
- 手动备份：我的 → 数据安全 → 立即备份
- 恢复：我的 → 备份记录 → 恢复（**高危操作，会用备份覆盖当前全部数据**），恢复后重启后端服务

## 生产部署注意事项

1. 复制 `backend/.env.example` 为 `backend/.env`，设置随机 `APP_SECRET_KEY`
2. 前端执行 `npm run build`，之后只需运行后端一个进程
3. 局域网访问：手机与电脑同一网络，访问 `http://<电脑IP>:8000`
4. PWA "安装到桌面" 需要 HTTPS 安全上下文（localhost 除外）；局域网 HTTP 下功能不受影响，正式公网部署建议配置 HTTPS 反向代理

## 运行测试

```bash
cd backend
python -m pytest tests -v
```

测试覆盖：登录与 RBAC 权限（401/403）、金额精度（0.1+0.2 类问题）、利润计算（单店铺/合并/区间边界/收入为 0）、软删除与恢复、审计日志、备份与导出、用户管理。
